# Movie Search App

Welcome to **Movie Search App**! This is a simple movie search web application that allows users to search for movies and get detailed information about them, such as the title, genre, director, starring actors, ratings, and more.

## Features
- **Search Movies**: Enter the name of any movie to get its details.
- **Movie Information**: View movie title, genre, actors, director, writer, IMDB rating, and worldwide collections.
- **Movie Poster**: See the movie poster displayed alongside its information.
- **Responsive Design**: Works well on both desktop and mobile devices.

## Technologies Used
- **HTML**: Used to structure the webpage and display content.
- **CSS**: Used for styling the app and ensuring a responsive layout.
- **JavaScript**: Used to fetch movie data from the OMDB API and dynamically display it on the webpage.
- **OMDB API**: Provides movie data based on the movie name entered by the user.
